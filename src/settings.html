说明 / 读不到数据怎么办
  1. 正常情况什么都不用做。硬件监控是地球桌面自带的一个后台服务（“EarthDesk Hardware Sensors”），安装时已经配置好：开机自动运行，没有窗口，也不在托盘里显示；它出错退出时 Windows 会自动把它重新拉起来，停了或者卡住时地球桌面也会自己重启它。
  2. 需要你操作的只有一种情况：上面出现修复按钮。点它，Windows 会问“你要允许此应用对你的设备进行更改吗？”，点是。它会重新安装读取传感器用的驱动（PawnIO）和后台服务，十几秒后状态变成“正常”。
  3. 修复后还是不行：
    • 杀毒软件（360、火绒、腾讯电脑管家等）可能拦截了驱动或服务。在它的拦截记录里选“允许 / 信任”，或把地球桌面的安装文件夹加入信任，再点一次修复。
    • 需要 Microsoft .NET Framework 4.8。Windows 10（2018 年 4 月以后的版本）和 Windows 11 都自带；老系统请从微软官网下载“运行时”安装（国内可直接访问）。
    • Windows 账户需要是管理员；普通账户点修复时需要输入管理员密码。
    • 运行记录在 C:\ProgramData\EarthDesk\sensors.log，把它发给开发者可以帮助排查。
  4. 以前单独装过 LibreHardwareMonitor 的话，现在已经用不着它了，可以退出或卸载。
  5. 没有硬件监控时，CPU、内存和磁盘照样显示，只是没有温度、风扇和显卡占用。
