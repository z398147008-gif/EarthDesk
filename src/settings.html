硬件监控

温度、风扇、显卡读数 检测中…
由内置的 LibreHardwareMonitor 提供，安装时已自动配置好。
使用说明 / 读不到数据怎么办
  1. 正常情况什么都不用做。安装程序已经装好了读取传感器用的驱动（PawnIO）、设置了开机自动在后台运行，并且只允许本机访问。状态显示“运行中”就说明一切正常。
  2. 显示“未运行”：点右上方的一键修复。Windows 会弹出“你要允许此应用对你的设备进行更改吗？”，点是。等 10 秒左右，状态会自动变成“运行中”，性能组件里就会出现温度和风扇。
  3. 点了修复还是不行：
    • 杀毒软件（360、火绒、腾讯电脑管家等）可能拦截了驱动或开机任务。在它的拦截记录里选择“允许 / 信任”，或把地球桌面的安装文件夹加入信任，然后再点一次一键修复。
    • 需要 Microsoft .NET Framework 4.8。Windows 10（2018 年 4 月以后的版本）和 Windows 11 都自带；老系统请从微软官网下载“运行时”安装（国内可直接访问），装完再点一键修复。
    • 如果你自己已经开着 LibreHardwareMonitor 或别的占用 8085 端口的程序，先把它退出（或者在它的“选项 → 远程 Web 服务器”里打开服务、端口设为 8085，也可以直接用）。
    • Windows 账户需要是管理员；普通账户弹窗时需要输入管理员密码。
  4. 自己检查：在浏览器里打开 http://127.0.0.1:8085/data.json，能看到一大段文字就说明硬件监控在工作。
  5. 没有硬件监控时，CPU、内存和磁盘照样显示，只是没有温度、风扇和显卡占用。
