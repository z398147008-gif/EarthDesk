怎么运行 地球桌面
=====================================

你不需要懂代码,按顺序双击三个文件就行。
中途所有窗口都不要关,看到「按回车关闭」再关。


第 1 步:双击【1-安装环境.bat】
-------------------------------------
会弹出一个「是否允许此应用对你的设备进行更改」→ 点【是】。
(需要管理员权限,是因为要装微软的 C++ 生成工具。)

然后它自己下载安装三样东西:
  · WebView2      —— 组件的显示引擎,你的 Win11 多半已经有了
  · C++ 生成工具  —— 最大的一项,好几个 GB
  · Rust          —— 编译这个程序用的
  · Tauri 工具    —— 打包用的

全程 20 到 30 分钟,大部分时间它在下载,屏幕可能很久不动,那是正常的。
可以去干别的,但别关窗口。

做完会显示绿色的「环境装好了」。
这一步一辈子只用做一次。


第 2 步:双击【2-运行.bat】
-------------------------------------
第一次会编译 3 到 5 分钟,屏幕刷一大片绿色的 Compiling,正常。

跑起来之后:
  · 地球铺满整个桌面,天气和机器状态两个组件浮在上面
  · 鼠标直接穿过组件,不影响你点桌面图标
  · 按 Ctrl + Alt + D 进入编辑模式,这时可以拖动组件、拖右下角缩放,
    靠近屏幕边缘或另一个组件时会自动吸附对齐
  · 再按一次 Ctrl + Alt + D 退出编辑模式
  · 右下角托盘里有个地球图标,右键 →【设置…】打开设置页:
    可以改城市、单独开关地球壁纸、天气组件、性能组件,以及组件里的每一块
    (逐时/每日预报,CPU/显卡/内存/磁盘/温度/风扇),还能调字号和层级。
    改完立即生效,不用重启。
  · 托盘右键 →【退出】关闭程序

注意:这一步开着的黑窗口关掉,程序就没了。
      想让它变成正常软件,做第 3 步。


第 3 步(可选):双击【3-打包成安装程序.bat】
-------------------------------------
编译 3 到 5 分钟,完了会自动打开一个文件夹,
里面有个 地球桌面_1.0.0_x64-setup.exe,双击安装。

装完之后它就是开始菜单里的一个普通软件,
不需要再开黑窗口,默认开机自启(设置里可以关)。

这个安装包可以直接发给朋友,他们什么都不用额外装:
  · WebView2 显示引擎、硬件监控(LibreHardwareMonitor + PawnIO 驱动)都已内置
  · 安装时会弹一次「是否允许更改」→ 点【是】,硬件监控就自动配置好了
  · 装完勾着「运行地球桌面」点完成,直接就能用
  · 在托盘右键 →【设置…】→ 位置,选国家 / 省 / 城市,天气和地球就换过去了
  · 硬件监控读不到时,设置页里有「一键修复」和详细说明
  · 安装包没有数字签名,Windows 可能提示「已保护你的电脑」:
    点【更多信息】→【仍要运行】即可。个别杀毒软件会拦截驱动或开机任务,选择允许。
  · 联网用到的服务(Open-Meteo 天气、NASA 卫星云图)国内都能直接访问;
    万一云图下载失败,会自动用内置云图,不影响使用。


第 4 步(只在用【2-运行.bat】试运行时需要):让风扇转速和显卡数据显示出来
-------------------------------------
安装包里已经内置并自动配置了这个工具,装了安装包就不用做这一步。
试运行时 Windows 没有公开接口能读主板风扇转速和显卡占用,
所以要借助一个免费小工具:

  1. 去 https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases
     下载最新的 zip,解压到任意位置
  2. 右键 LibreHardwareMonitor.exe →【以管理员身份运行】
     (不用管理员:读不到主板风扇,而且 Web Server 会绑不上端口,
      静默失败,看起来像开了其实没开)
  3. 菜单 Options → Remote Web Server → Run
     要看到 Run 前面有勾才算开了。只打开 Port 设置不算。
  4. 验证:在浏览器打开 http://127.0.0.1:8085
     能看到一张传感器表格 = 成功;打不开 = 第 2 或第 3 步没成
  5. 建议再勾上 Options → Start Minimized 和 Run On Windows Startup

做完这步,机器状态组件里的温度、风扇转速、显卡占用/显存/功耗就都有了。
不做也没关系,CPU、内存、硬盘照常显示,缺的部分会明确写出来。


出错了怎么办
-------------------------------------
任何一步如果屏幕上出现红色的 error,
把那个窗口截图发给我,我来改。

不用自己琢磨,这些报错基本都是环境问题,不是你操作错了。


想调整外观
-------------------------------------
配置文件在这里(地址栏粘贴就能打开):
  %APPDATA%\EarthDesk\config.json
  (以前的 %APPDATA%\OsakaDesk 会在第一次启动时自动搬过来)

用记事本打开,常用的几项:

  ui_scale      组件文字整体大小,嫌小就调 1.2 / 1.4
  z_mode        组件在哪一层。默认 desktop(贴在桌面上,不挡窗口)。
                如果组件显示不正常,改成 bottom

  wallpaper 里面:
  camera_distance  相机离地心几个地球半径。调大 → 地球变小、天空变多
  focal_length     焦距,调大 → 拉近
  axis_offset_y    整个画面上下移动,调大 → 地球往下沉
  live_clouds      true 用当天实时云图(需要联网),false 用内置云图
  stars            星空亮度,0 关掉
  sun / moon       太阳、月亮亮度,0 关掉
  render_scale     如果觉得卡,调成 0.75
  cloud_opacity    云的浓度
  city_lights      夜晚城市灯光的亮度

  sensors 里面:
  lhm_url          温度/风扇数据的地址。默认 http://127.0.0.1:8085/data.json
                   (内置的硬件监控);读别的电脑时改成那台机器的地址

改完保存,退出程序再打开就生效。
不确定改什么就直接问我。

配置文件坏了或想恢复默认:直接删掉 config.json,下次启动会重新生成。
程序升级后如果默认值变了,旧配置会自动重置一次(位置、传感器、热键保留)。


关于月亮
-------------------------------------
月亮是按真实位置画的,不是贴上去的装饰。

相机悬在你头顶三个地球半径的地方,地球本身挡掉了大半个天空,
能看见的只有地平线上方一条窄带。实际算下来,60 天里月亮大概
只有 18 个小时会飘进画面 —— 一次一两个小时,几天一次。

看见了是运气,看不见是正常的。想多看到一点,把 camera_distance
调大(比如 5),地球会变小,天空变多。

太阳更少见:白天它在相机背后,晚上它在地球背后。
