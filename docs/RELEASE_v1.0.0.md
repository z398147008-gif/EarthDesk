# 地球桌面 1.0.0

实时光照的地球壁纸 + 天气组件 + 机器状态组件，一个安装包装完就能用。

![地球桌面](https://raw.githubusercontent.com/z398147008-gif/EarthDesk/main/docs/screenshot.png)

## 安装

下载下面的 `地球桌面_1.0.0_x64-setup.exe`，双击安装。

- 安装过程中会弹一次「是否允许此应用对你的设备进行更改」，点【是】——它在这一步把硬件监控（温度、风扇、显卡占用）需要的驱动和开机任务配好，之后日常使用不会再弹。
- 安装包没有数字签名，Windows 可能提示「已保护你的电脑」：点【更多信息】→【仍要运行】。
- 装完勾着「运行地球桌面」点完成，直接就能用；默认开机自启，设置里可以关。
- 系统要求：Windows 10 1803 及以上 / Windows 11，64 位。WebView2 和 .NET 都已内置或自动处理。

## 用法

- 托盘右键 →【设置…】：改城市（国家 / 省·州 / 城市三级下拉，内置全球 2.5 万个城市，中日港澳台为中文名）、开机自启、组件层级和大小、每个组件和每一块内容的开关、硬件监控状态与一键修复。
- `Ctrl + Alt + D` 进出编辑模式，可以拖动、缩放组件，靠近屏幕边缘或另一个组件时自动吸附。
- 托盘右键 →【退出】关闭。

## 这一版里有什么

- **地球**：太阳位置按真实时间算；云是当天的气象卫星图（葵花 9 号可见光 + 红外，十分钟级，全球底图每三小时更新）；物理大气散射；按水深上色的海水；真实星表的星空、月亮的真实位置与相位。构图和调色对着 Apple 的地球壁纸逐像素标定。
- **天气**：Open-Meteo，当前 + 逐时 + 七天，按天气和昼夜变色的卡片。
- **机器状态**：CPU（总体与每核）、内存、磁盘来自系统接口；温度、风扇转速、显卡占用 / 显存 / 功耗来自内置的 LibreHardwareMonitor。
- 多显示器：每块屏幕一颗地球，各自按自己的比例构图。
- 壁纸平时不动，只在时钟走过一段或云图更新时重绘一次，所以待机时几乎不吃 GPU。

## 联网

只用三个服务，中国大陆可直接访问：Open-Meteo（天气）、NASA GIBS（卫星云图）、matteason 全球云图。拉不到时自动退回内置云图，不影响使用。不收集、不上传任何数据。
