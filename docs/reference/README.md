# 苹果地球参考截图

iPad（2000×1499）上的系统地球壁纸，文件名里是拍摄时的日本时间。
渲染对比时用同一时刻、同一尺寸出图，逐像素取色。

- `apple-night-2026-09-26-0008.webp` 深夜，光晕颜色的参考
- `apple-morning-2026-09-23-0810.webp` 早上
- `apple-lock-2026-09-22-1208.webp` 正午（锁屏）
- `apple-day-2026-09-23-1502.webp` 下午
- `apple-dusk-2026-09-22-1816.webp` 傍晚，晨昏线

注意：苹果的云是固定的。上面几张不同时间的截图里，同一块区域的云
相关系数有 0.95–0.99，连光影都一样（是预先烘焙好的），不是实时天气。
我们保留实时卫星云，只模仿它的画法。
